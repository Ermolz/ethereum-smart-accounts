# Ethereum Smart Accounts: EIP-7702

Сім слайдів і пояснення для тих, хто вперше знайомиться зі смарт-акаунтами Ethereum. Головне питання: як додати звичайному акаунту програму, зберегти його адресу та не переплутати нові можливості з гарантіями безпеки. Виступ розрахований приблизно на 4–5 хвилин.

**[Відкрити презентацію](https://ermolz.github.io/ethereum-smart-accounts/)** · [Репозиторій](https://github.com/Ermolz/ethereum-smart-accounts)

Коротка відповідь: **EIP-7702 дозволяє наявному EOA використовувати код гаманця за своєю адресою**. EOA — акаунт, яким керує приватний ключ. Назва «третій тип» неформальна: йдеться про EOA з делегованим кодом, а `0x04` — номер нового типу транзакції. Механізм працює в Ethereum після Pectra, активованого 7 травня 2025 року. Пояснення й підтвердження зібрані в [навчальному посібнику](02-learning-guide.md) та [джерелах](05-sources.md).

## Порядок підготовки

1. Почни з [посібника](02-learning-guide.md): він пояснює адресу, ключ, код і два різні дозволи.
2. Відкрий слайди поруч із [нотатками для себе](06-personal-notes.md). До кожної схеми є проста фраза та підказка, куди дивитися.
3. Прочитай [виступ](03-speech.md) вголос із перемиканням слайдів. Час у таблиці — орієнтир; реальну тривалість треба виміряти під час репетиції.
4. Перевір себе за [питаннями до захисту](04-defense-preparation.md). У [звіті](01-technical-report.md) шукай деталі, які ще залишилися незрозумілими.

Якщо є лише 15–20 хвилин, скористайся [коротким маршрутом повторення](06-personal-notes.md#повторення-за-1520-хвилин).

## Перегляд

Онлайн відкрийте посилання вище. Локально відкрийте `index.html` у сучасному Chrome, Edge або Firefox. `presentation.html` також відкриває презентацію та зберігає номер слайда в адресі.

Стилі та JavaScript збережені в репозиторії; для показу слайдів інтернет не потрібен. Посилання на зовнішні джерела потребують з’єднання. Встановлення пакетів і збірка відсутні.

| Дія | Керування |
|---|---|
| Наступний / попередній слайд | Кнопки на панелі, → / ←, Page Down / Page Up |
| Наступний слайд | Space поза інтерактивними елементами |
| Перший / останній слайд | Home / End |
| Повноекранний режим | Кнопка на панелі або F; Esc — вихід |
| Нотатки доповідача | Кнопка на панелі або N |
| Посилання на слайд | `#slide-1` … `#slide-7` |

Автоматичного перемикання немає. На вузькому екрані вміст перебудовується для вертикального читання. Режим друку показує всі слайди.

Якщо браузер або вбудований переглядач блокує Fullscreen API, презентація показує повідомлення. У настільному Chrome чи Edge скористайтеся **F11** або відкрийте сторінку в окремій вкладці браузера.

За потреби локального HTTP-сервера виконайте з кореня репозиторію:

```sh
python -m http.server 8766 --bind 127.0.0.1
```

Відкрийте `http://127.0.0.1:8766/`.

## Межі матеріалу

Це пояснення протокольного механізму, а не аудит конкретного кошелька. Числові сценарії умовні; матеріали не підключають гаманець і не надсилають транзакцій. Можливості на кшталт passkeys, recovery, session keys чи спонсорування залежать від реалізації та інфраструктури.

Пов’язана презентація: [архітектура Uniswap V2, V3 і V4](https://ermolz.github.io/uniswap-architecture/). Проєкти мають окремі репозиторії та публікації.
